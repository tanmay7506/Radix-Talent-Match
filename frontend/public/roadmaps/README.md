# RADIX Skill-Gap Roadmap PDFs

Place the 12 canonical skill roadmap PDF files into this directory (`frontend/public/roadmaps/`).

When placed here, Vite serves them directly as static assets at `/roadmaps/<filename>`, enabling one-click opening in a new tab without external dependencies or backend routes.
